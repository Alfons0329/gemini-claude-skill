# Interview-Me — Output Document Template

The document written at the end of an interview.

**Write for a stranger.** A fresh session with no memory of the conversation must be able to start implementing after reading this file alone. An empty section means a gap went unresolved — say so explicitly rather than leaving it blank.

**When the input was an existing document**, do not emit this template as a new file. Fold each result into the section it belongs to in that document, and shrink its open-questions list as items close. Use the template below only when starting from a bare topic.

---

```markdown
# {TOPIC}: Shared Understanding

> Generated by /interview-me · {N} rounds · {M} questions
> To implement: start a fresh session and read this file first.

---
