# Specification Index: Harness Engineering (`harness-eng`)

- **[`spec-phase-2.md`](spec-phase-2.md)** — deferred. A portable-kernel extension (config seam, cross-session continuity, team onboarding) for when scope grows past a single IC. Not being built now.
